# Humanity Help Hub

## About the Project
Humanity Help Hub is a web-based project designed to connect people who need help with people who are willing to help.

## Features
- Request Help
- Offer Help
- Simple and user-friendly interface
- Helps connect people with volunteers
- Easy navigation

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite Database

## Purpose
The main purpose of Humanity Help Hub is to use technology for social good and make it easier for people to seek and provide help.

## Project Structure
- `main.py` – Main Python file
- `app.py` – Flask application
- `templates/` – HTML pages
- `static/` – CSS and other static files
- `humanity_help.db` – Database
